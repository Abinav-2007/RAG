chroma_db/
├── chroma.sqlite3
│   └── Tables:
│       ├─ collections       (metadata about collections)
│       ├─ documents         (chunk text content)
│       ├─ embeddings_queue  (embedding references)
│       ├─ metadatas         (chunk metadata: source, page, etc.)
│       └─ collection_metadata (collection-level settings)
│
├── [UUID-1]/
│   ├─ data_level0.bin       ← HNSW Index Level 0 (vectors here)
│   ├─ header.bin            ← HNSW Header
│   ├─ length.bin            ← HNSW Length
│   └─ link_lists.bin        ← HNSW Link Lists
│
└── [UUID-2]/
    └─ [Registry collection - similar structure]

Two Collections:
┌──────────────────────────────────────────────────────────────┐
│ rag_documents (Main Vector Store)                            │
├──────────────────────────────────────────────────────────────┤
│ ID: "document__bge-small-en-v1.5__p0__c2"                   │
│ Document: "The main topic is about..."                      │
│ Embedding: [0.021, -0.113, ..., 0.089]  (384 dims)          │
│ Metadata: {source: "document.pdf", page: 0, ...}            │
│                                                              │
│ Count: 240 chunks (vectors searchable)                       │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐

║                         CLI INTERFACE FLOW                                 ║
╚════════════════════════════════════════════════════════════════════════════╝

python main.py ingest [--source FILE] [--force] [--clean-orphans]
         │
         ├─→ Find all .pdf, .txt, .md, .docx in data/
         │
         ├─→ For each file:
         │   ├─ Check registry (fingerprint comparison)
         │   ├─ Skip if unchanged
         │   ├─ Delete old chunks if changed
         │   ├─ Load → Chunk → Embed → Store
         │   └─ Update registry
         │
         └─→ Print summary statistics

python main.py status
         │
         ├─→ Show vector store size (total chunks)
         ├─→ List all registered documents
         ├─→ Show chunks per document
         ├─→ Detect orphaned documents
         │
         └─→ Print full report

python main.py query QUESTION [--llm PROVIDER] [--top-k N]
         │
         ├─→ Embed question
         ├─→ Search ChromaDB
         ├─→ Build prompt
         ├─→ Call LLM
         │
         └─→ Print answer with citations

This architecture ensures:
✅ No duplicate chunks (stable IDs + registry)
✅ No stale chunks (auto-cleanup)
✅ Accurate costs (token-based)
✅ Fast search (HNSW index)
✅ Persistent storage (SQLite + binary index)
✅ Complete RAG system (search + LLM)
✅ Easy CLI interface (ingest/status/query)
